# 一键改稿与模型设置

在“反馈与改稿”输入需求，选“当前页”或“整份讲品稿”，然后点“交给 Codex”。工作台先保存当前草稿和反馈，再调用本机 Codex CLI。页面显示任务状态；完成后自动读取修改建议，预览后点击“应用到草稿”，最后保存。生成期间若稿件发生变化，建议不会覆盖新版，需重新提交。

默认模型 `gpt-6-astra`，推理强度 `medium`。下拉选项来自本机 Codex 模型缓存，也可填写自定义模型 ID。选择并点击保存设置，或提交任务时自动保存。账号不支持所选模型时显示错误，不自动换模型。每个人使用自己的本机登录与额度。设置仅存 `.local/codex-settings.json`，不放入文稿包或 Git。

首次使用安装官方 Codex CLI（Node 环境中 `npm install -g @openai/codex`），执行 `codex login` 并选择 ChatGPT 登录。使用 `codex login status` 确认。需要支持 `exec --ignore-user-config --output-schema` 的 CLI 版本。若未找到 CLI、登录过期、网络失败或额度不足，工作台会报告错误。先在终端修复后，在网页重新提交；无需分享登录凭证。

后台以只读沙箱运行，使用独立临时目录，显式指定模型与强度，不加载个人 config.toml，不传 API Key 环境变量。读取任务输入后输出结构化建议，由工作台校验和写入；不会自动运行 Git 提交、合并或应用到固定播出版本。

自动改稿支持现有页面的标题、副标题、要点、讲述提示和四种版式。素材、页 ID、来源与轮次由程序保留。图片/GIF/视频二进制不会发送给该文字改稿任务；需要看图判断、替换素材、新增功能时仍在 Codex 对话中操作。所有任务带上产品全称、两轮讲品、通用学段、品牌排版规则，但不自动继承聊天历史。

可取消任务；最长15分钟。服务正常退出会停止正在运行的任务，重启时会标记旧任务为中断。反馈保留在稿件，取消和失败不会应用建议。取消后等子进程结束再重试。不要在任务运行时关闭电脑。

开发验收：`npm run test:acceptance`。自动测试使用模拟 CLI，不消耗额度；真实模型冒烟验证使用独立空白稿，不使用业务文稿。在线后台仍然需要可访问 Codex 服务的网络。
