# 一键改稿与模型设置

在“反馈与改稿”输入需求，选“当前页”或“整份讲品稿”，然后点“交给 Codex”。工作台先保存当前草稿和反馈，再调用本机 Codex CLI。页面显示任务状态；完成后自动读取修改建议，预览后点击“应用到草稿”，最后保存。生成期间若稿件发生变化，建议不会覆盖新版，需重新提交。

默认选择“跟随本机 Codex 设置”：工作台不强制指定模型或推理强度，直接使用该电脑 Codex CLI 的服务商、认证和模型。下拉选项来自本机模型缓存，也可填写第三方模型 ID；只有显式选择时才覆盖 CLI 的模型或强度。旧版自动保存的 `gpt-6-astra` / `medium` 默认项会自动改为跟随本机。设置仅存 `.local/codex-settings.json`，不放入文稿包或 Git。

首次使用安装 Codex CLI，并先在终端确认 `codex exec` 能按自己的配置正常调用。可以使用 ChatGPT 登录，也可以按本机 Codex 配置使用 API Key 或第三方模型服务；不要求购买 ChatGPT 会员。工作台不会在界面显示或保存密钥，也不会把密钥提交到仓库。启动工作台的进程必须能访问同一个 `CODEX_HOME` 和服务商所需的环境变量；修改这些环境变量后请重启工作台。CLI 需支持 `exec --output-schema`。若未找到 CLI、密钥无效、服务不兼容、网络失败或额度不足，工作台会报告错误。第三方服务需支持 Codex CLI 的请求格式、结构化输出；改稿使用参考图时还需支持图片输入。

后台以只读沙箱运行，使用独立临时目录，并沿用个人 `config.toml` 中的服务商配置及启动进程继承的环境变量。读取任务输入后输出结构化建议，由工作台校验和写入；不会自动运行 Git 提交、合并或应用到固定播出版本。

未提出视觉或结构要求时，Codex 默认使用公司模板。明确提出排版、结构、颜色、留白、字号、图文比例等要求时，允许自由排版：可组合分区、网格、卡片、流程、对比、渐变与几何装饰，不局限于四种模板或三种配色。语义由模型理解，不做关键词硬切换。明确要求保留现有设计时也可只改文案。

自由排版随页面保存在 `.deck.zip`、播出版本和离线 HTML 中。所有文字仍绑定标题、副标题或要点字段，可继续在“页面编辑”里改文字。Logo 和阿里普惠体始终由工具提供；媒体复用原有触控播放组件。设计树只表达展示布局，不运行生成的脚本、不加载额外外链。

“页面编辑 → 改回默认排版样式”只影响当前草稿页：去掉自由设计、恢复品牌原色，按有无素材和要点选择公司模板；保留文字、素材、来源、页 ID 与轮次。操作前自动创建版本，可恢复改版前效果，点击保存后才写入当前草稿。

素材、页 ID、来源与轮次由程序保留。图片/GIF/视频二进制不会发送给此任务；需要新增图片视频、改动整份稿件页数或工作台功能时仍在 Codex 对话中操作。任务带上产品全称、两轮讲品、通用学段与设计规则，但不自动继承聊天历史。

可取消任务；最长15分钟。服务正常退出会停止正在运行的任务，重启时会标记旧任务为中断。若请求超出当前能力，显示“需要补充说明”及模型的具体解释；最近一次模型结果保存在 .local/codex-last-result.json 便于排错，不进入文稿包或 Git。反馈保留在稿件，取消和失败不会应用建议。取消后等子进程结束再重试。不要在任务运行时关闭电脑。

开发验收：`npm run test:acceptance`。自动测试使用模拟 CLI，不消耗额度；真实模型冒烟验证使用独立空白稿，不使用业务文稿。在线后台仍然需要可访问 Codex 服务的网络。
