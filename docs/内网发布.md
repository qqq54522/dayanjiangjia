# 发布演示链接

工作台顶部「发布」会将当前草稿生成为包含字体、图片、GIF、视频的独立 HTML，再通过内网上传网关发布。发布后返回 HTTPS 播放链接。每次使用独立对象键，不覆盖旧链接。

首次使用时，在本机 `.local/publish-config.json` 配置：

```json
{
  "gatewayUrl": "https://内网上传网关地址",
  "apiKey": "网关 API Key"
}
```

也可以用本机环境变量 `UPLOAD_GATEWAY_URL` 和 `UPLOAD_API_KEY` 覆盖。配置文件、发布记录、上传内容均留在 `.local/`，不进入 Git。不要把 API Key 写进源代码、前端页面或文稿包。

上传使用网关的 `POST /v1/presign` 和返回的预签名 `PUT` 地址。必须由网关返回 `public_url`，工作台才会显示可分享链接。发布记录保存在 `.local/publications.json`；记录只供查找链接，不管理远端文件。网关如设置存储生命周期，界面会显示其提示。旧链接不会随本机草稿的后续修改自动更新。
