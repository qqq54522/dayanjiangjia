# 项目片段库与独立投屏

每个项目的 `clips` 保存名称、学段、学科和本机 MP4 或 GIF 引用。GIF 保留原始字节与动画；视频由本机 FFmpeg 处理为 H.264 / AAC MP4。当前草稿、版本及 ZIP 导出均携带相应片段。发布时片段与页面素材一起交给发布网关，只有播放内容进入独立 HTML，讲述提示和内部反馈不进入播放文件。

## 使用

1. 工作台顶部「精彩片段」上传 GIF、MP4、MOV、QT、M4V、WebM、MKV 或 AVI（单个最多 512 MB），可以改名称、学段、学科，调整顺序或移除。上传和编辑自动保存，支持撤销。
2. 发布当前项目。发布过程会上传所有被引用的视频和动图，生成一个含全部页面和片段的播放链接；历史链接不会被改写。
3. 平板打开播放链接，底部缩略图默认收起。点击 PPT 或周围空白处可反复展开／收起，也可以点击页码按钮；展开后横向滑动、点击缩略图跳页。缩略图宽、高按原尺寸的三分之二显示，底部条带同步降低高度；缩略图底部页码条使用该页所属分组的颜色，与分组标记一致；未分组页面使用默认底色，选中页仍有蓝色边框。点击缩略图保持横向浏览位置，不将选中页移到中间；上下页或重新展开时，仅在当前缩略图不在可见区时做最小幅度滚动。卡片、图片、视频和弹窗操作不触发展开／收起。右侧片段库展开时，PPT 保持比例并缩小让位。
4. 点击「全屏」进入当前浏览器的全屏模式，隐藏地址栏和标签栏；再次点击「退出全屏」或按 Esc 返回，保留当前页。此操作不需要投屏服务。
5. 需要独立观众画面时，点击单独的「连接观众大屏」创建连接，复制观众链接，在大屏电脑浏览器打开，点击「开始演示并全屏」。平板保留控制台，大屏只显示演示内容。
6. 平板选择片段后，在 PPT 画面内部的黑色浮层从头播放，不遮挡侧栏和底部操作区。点击视频外的黑色空白、再次点击侧栏当前片段或按 Esc 返回原页；点击其他片段直接切换，翻页则关闭片段并跳转。浮层没有标题栏或外框。视频支持暂停和跳转，GIF 保留原文件的循环规则，每次打开创建新的动画解码实例。返回演示同步到大屏。返回保留当前页，片段库不属于任何一张幻灯片。

## 同步服务部署（一次性）

静态播放 HTML 本身不能跨设备传递控制指令，普通屏幕镜像也不能自动隐藏平板控制台。需要一台两端都能通过 HTTPS 访问的同步服务。服务仅保存短期页码、片段 ID 和播放状态，不接收 PPT、视频或项目名称。

在公司受控服务器部署本仓库的 Node.js 24 运行环境：

```sh
PRESENTATION_RELAY_PORT=8790 PRESENTATION_ALLOWED_ORIGINS=https://已配置的发布域名 node scripts/presentation-relay.mjs
```

进程仅监听 `127.0.0.1`。由公司现有反向代理将独立的 HTTPS 地址转发至该端口，转发路径保持 `/rooms`、`/rooms/<id>/state`。GET `/health` 可检查运行情况。可通过逗号分隔多个允许的发布源；生产部署应设置精确允许源。反向代理不得缓存这些接口，须保留 Authorization 请求头并允许预检请求。

在工作台「精彩片段 → 独立投屏连接设置」填入 HTTPS 服务根地址，保存后重新发布。配置仅存本机忽略的 `.local/playback-config.json`；播放 HTML 携带公开服务地址，不携带网关 API Key。

每个演示连接使用独立的控制令牌和只读观众令牌，连接有效期为 6 小时。观众链接把令牌放在 URL 片段中，HTTP 请求使用 Authorization 头。不要把观众链接发到公开渠道。服务有请求大小、房间数量及创建频率限制；公网部署仍须遵循公司的访问控制和网络策略。

工作台本机「预演」内置同协议的隔离连接，仅用于在本机浏览器预览两端，不会将工作台改为对外监听。用于其他设备的正式链接必须配置并发布可访问的 HTTPS 同步服务。

## 兼容性与边界

- 平板端使用浏览器播放控制台；接收端使用支持 HTML5 视频的浏览器。系统全屏是否被允许仍由浏览器决定，界面会保持观众模式，不显示编辑器或平板导航。
- 观众首次需要点击开始以允许声音播放。建议使用 H.264 / AAC 编码的 MP4。
- 无同步服务时，项目上传、保存、ZIP、发布、离线播放、侧边片段库和缩略图导航仍可用；跨设备独立投屏会明确提示尚未配置，不会伪装成已连接。
- 片段修改后须重新发布。已发布的历史页面与素材保持固定。

## 乐播投屏

乐播的扫码「屏幕镜像」会复制平板的整个画面，无法由普通播放网页将控制台从镜像中排除。使用本功能的独立观众画面时，需大屏侧的电脑或其他设备通过浏览器打开观众链接；单独的乐播镜像接收器不能替代浏览器。若现场只有乐播镜像，需要另行接入厂商支持的投屏能力，不能把本机全屏按钮当作双屏输出。官方说明：https://www.lebo.cn/UseHelp.jsp 。

视频处理需要本机 FFmpeg 和 FFprobe；缺失时按错误提示运行 `npm run setup:native`，不需要用户自行手动改扩展名。原文件不会覆盖已有素材；兼容的 H.264 / AAC MP4 直接复用，其他视频转换后保留声音并与项目一起导出。受损、加密或本机解码器不支持的文件会明确报错。
