# 每页的素材与排版意图

画布下方直接管理素材：多选上传图片、GIF、MP4，预览缩略图，替换、移除、前移与后移。移除只从本页移除，原素材和历史版本不被删除。主标题仍在右侧页面编辑中修改。

## 先选表达重点

- 突出画面：保留主标题、Logo 与媒体，副标题和标签不展示，但不会删除。
- 图文并重：左约 1/3 为讲解与标签，右约 2/3 为素材。
- 突出文字：左约 3/5 为文字，右约 2/5 为素材。
- 帮我安排：有说明时采用图文并重，没有说明时突出画面。单张竖图在画面模式中居中完整显示。

多素材可选逐张讲解或同时平铺。平铺支持图片、GIF 与视频混合，各自仍可放大。素材超过四个会提示考虑拆页或逐张讲解。默认完整显示；只有用户选择填满或正方形裁剪时才裁剪图片。视频始终完整显示，放大图片显示原图。

这些设置适用于默认品牌模板。已有自由设计/其他配色不会被预设直接覆盖；可先使用“改回默认排版样式”，或让 Codex 继续自由设计。

## 与 Codex 协作

右侧顶部可切换“文字内容”“素材与排版”“Codex 改稿”；页面样式位于“素材与排版”内。填写“本页排版意图”后，在“Codex 改稿”填写修改需求并点“交给 Codex”，会自动携带当前素材与排版要求。保存的 composition 字段随文稿、版本、建议和 ZIP 一起保存。Codex 可以建议新的预设组合或自由布局，仍需预览后应用。

当前任务范围内的本地 PNG/JPEG/WebP 最多附带 12 张给本机 Codex；顺序与页面/素材编号对应。未附带素材会明确列出。GIF、视频、远程 URL 不附带内容，需要创作者描述重点或另传静态截图。不会把未看到的素材当作已理解的事实。常规验收采用模拟 Codex，不自动消费真实模型任务额度。

工具代码不包含业务素材；以上操作只在本机进行，用户主动提交 Codex 改稿时才通过本机 Codex 登录使用其模型服务。

## 素材与样式入口
- 点击「添加图片 / GIF / 视频」打开拖拽上传框，也可点击框内选择多个文件。
- 在素材卡片上拖动可以排序。鼠标悬浮时显示替换、移除图标；触屏上图标常显。
- 右侧「页面样式」用用途说明选择章节开场、文字讲解、并列要点、重点提示或数据对比。含图片/视频时，在「素材与排版」控制图文比例。
- 顶部「样式示例」可预览并追加六页可编辑示例。图表要点每行填写「名称|数值」，当前量程固定 0—100；示例数据不代表业务结果。
- UI 不再使用分组、配色切换。旧文稿的数据字段保留读取兼容。
