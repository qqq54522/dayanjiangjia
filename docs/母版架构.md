# 母版架构

母版属于工具，不属于演示项目。当前开发期只维护一套已确认的 `onion-comic@1.2.0`，不保留旧母版或升级入口。现有页面与保存版本的内容保留，显示时统一采用当前母版。已经导出的独立 HTML 不会被修改。

## 文件与资源

- `masters/onion-comic/1.2.0/manifest.json`：ID、版本、渲染器、样式与背景校验值、字体和配色。
- 同目录 `styles.css` 与 `assets/background.png`：当前漫画母版及批准的背景原图。
- `lib/masters.ts`：母版注册表；同一母版 ID 统一解析为当前定义，未知 ID 明确报错。
- `lib/master-resources.mjs`：安装、校验背景，读取时规范化页面引用；保留明确的自定义背景。
- `lib/presentation-base.css`：共用画布、播放器、Logo 与基础布局。
- `scripts/build-masters.mjs`：组装 `public/deck.css`；不直接编辑生成文件。

## 呈现与编辑

框内排版结合 Codex 提供的语义重点、图片比例、文字长度与栏宽判断。作者可调整重点、对齐、图文位置与原句高亮。不得通过无限缩字、截断或隐藏关键内容解决密度问题。

分组在左侧页面列表设置，使用顶部色条与同色标签；颜色为松绿、陶红、莓紫、暖棕。分组身份在不连续页面间保持一致。

ZIP 携带页面实际使用的背景、正文素材及字体，不包含可执行母版代码。导入后使用工作台当前母版。需冻结外观时导出独立 HTML。

## 后续扩展

新增不同风格时增加独立母版 ID、素材包与样式命名空间，注册 renderer 并验证资源。现阶段不为尚未发布的历史版本保留兼容分支；正式发布后的版本策略另行确定。

运行 `npm run test:acceptance` 检查资源校验、ZIP 往返、HTML 导出与渲染。
