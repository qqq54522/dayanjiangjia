# 字体与文稿包

字体：Alibaba PuHuiTi 2.0。400 → 55-Regular、500 → 65-Medium、800 → 105-Heavy、900 → 115-Black。保留完整原始 TTF，不进行字体子集化或轮廓转换；不将字体二进制放进 GitLab。字体文件保存在 `.local/fonts/`。初始化优先复用本机安装，否则从字体官方网站对应的文件源获取。字体官网与使用条款入口：https://www.alibabafonts.com/ 。程序不会自动接受网站协议。

公司设计表核对了字体家族、以上字重及 blue-50 #518AFF、yellow-50 #FFD633。Deck 字号使用画布相对单位适配投屏；不直接使用 App 的 20–36px 字号。截图中指定的字体规则优先；原文件内版权信息保留。完整法律声明尚未完成读取，不能将本实现当作独立字体分发许可的法律判断。

ZIP 内结构：

- manifest.json：格式标识 onion-deck-zip-v1，文稿/反馈/版本、素材引用和 SHA-256 校验。
- assets/：去重后的原始图片、GIF、MP4。
- fonts/：四个原始 TTF 字重。
- FONT-NOTICE.txt：字体出处信息。

导入不直接解压路径，而是验证全部引用、素材格式及哈希，再以内容哈希保存素材。只接收 ZIP，不接收旧 JSON。原有本机数据库和素材不迁移、不删除。原素材和字体直接打包，避免 Base64 体积膨胀；独立 HTML 为实现单文件播放会使用 Base64。

视频建议使用 H.264 + AAC MP4。MP4 是容器，浏览器对其他编码的支持不同；不能解码时会显示提示。默认静音、无自动播放。点击原生控制区播放/暂停、拖动进度，用户主动开启声音。视频放大时底部“收起视频”关闭，不用点击画面关闭。视频进度手势不触发轮播，切换素材/页面时暂停。

不设置视频与 ZIP 的人为字节上限。当前 ZIP 编解码在内存执行，大文件需要足够内存；ZIP32/运行时也有物理限制，并不代表无限容量。
