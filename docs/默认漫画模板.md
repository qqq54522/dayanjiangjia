# 默认漫画模板

采用已确认的蓝色漫画片场：阿里普惠体 2.0、Logo 蓝 #1EB2FF、黑白黄蓝配色。上方水平深色白字标题带细横纹与斜向色带，右上官方 Logo 周围局部淡化，左下保留课程拼图和稀疏网点。开场标题框倾斜 1.5 度。

- 默认品牌配色使用新模板；已有自由设计和其他配色不覆盖。“改回默认排版样式”可回到新模板。
- 图片、GIF、视频页采用上标题、大媒体区；有补充文字时留出底部区域。文字页使用不透明白色面板。开场页保留大标题。
- 标题与正文自动适应预留区域；内容过多时字号会缩小，建议拆页保持投屏可读性。
- 编辑、预演、独立 HTML 共用同一个模板与适配逻辑。

## 背景与协作

默认母版现作为 `masters/onion-comic/1.0.0/` 内置样式包随工具分发，包括用户确认的课程背景。无需在每个稿件目录放置 `theme/background.png`。服务器启动会校验并安装素材，缺失时明确报错。

页面记录母版 ID、版本和实际背景引用；已有自定义背景不覆盖。ZIP 携带背景、字体与母版引用，HTML 内嵌样式及资源。具体扩展、兼容与版本策略见 [母版架构](母版架构.md)。业务素材和字体二进制仍不进 Git。

## 播放时的列表聚焦
文字讲解与并列要点页，黄色表示正在讲解的条目。默认第一项高亮，播放模式点按任意整行/卡片切换焦点，也支持键盘 Enter/空格。切页或返回该页重置为第一项，状态不写入文稿。导出 HTML 使用相同交互。图表及深色重点页的静态强调规则不受影响。
