# 母版样式包

母版属于工具，不属于某个演示项目或数据目录。当前内置 `onion-comic@1.0.0`，保留已确认的漫画课程背景、字体和版式。

## 文件职责

- `masters/onion-comic/1.0.0/manifest.json`：ID、版本、名称、渲染器、样式路径与校验值、字体要求、配色及背景来源。
- 同目录 `styles.css`：当前漫画母版的样式源文件。
- 同目录 `assets/background.png`：经用户确认作为工具母版资源分发的课程拼图。允许随内部 GitLab 仓库提交；不是业务文稿。
- `lib/presentation-base.css`：媒体播放、画布、Logo 等共用样式与旧版兼容规则。
- `lib/masters.ts`：前后端共用注册表、默认母版、引用校验及资源 URL。
- `lib/master-resources.mjs`：校验并安装母版素材，补齐旧稿缺省引用，不修改原对象。
- `scripts/build-masters.mjs`：校验样式包并组装 `public/deck.css`。后者保留为兼容构建产物，不直接编辑，测试检查两者一致。
- `Scene` 根据注册的 renderer 分派结构化/旧版内容到当前 `comic-v1` 渲染器。渲染器是工具代码，不接受文稿包内的可执行代码。

## 数据与生命周期

页面引用 `master: {id: 'onion-comic', version: '1.0.0'}`，不使用漂移的 latest。旧稿没有引用时解释为当前兼容母版，读取返回补齐数据，不直接写库；下次正常自动保存时落盘。已有背景引用及明确空背景均保留。

启动时从工具内置包校验背景 SHA-256，安装到当前数据目录的内容寻址 `/media/<sha256>.png`。因此切换 DECK_DATA_DIR、删除所有页面、新同事首次安装，都不依赖其他稿件目录的 `theme/background.png`。目录缺少/文件损坏时停止启动或构建，不能悄悄退化成无背景。

新建页面、样式示例继承当前母版；从零新建使用默认母版。空白页仍显示空白创作引导，写入内容后才展示母版。单页生成应用时保留目标页母版与自定义背景；整稿改编目前采用默认母版。其他母版的转换路径随其注册另行实现，不能宣称仅加一个配置即可获得新的布局引擎。

ZIP 保留引用，并携带页面实际使用的背景、正文素材与字体。另一台同版本工作台可离线导入。不支持的母版版本明确报错，要求升级；不静默套成另一母版。独立 HTML 内嵌当前 CSS、字体和背景，是冻结展示外观的交付形式。ZIP 不携带任意可执行渲染器代码。

## 增加或升级母版

1. 新建独立目录 `masters/<id>/<semver>/`，复制经过审定的工具级资源并记录校验值、来源与字体要求。
2. 注册到 `masterCatalog`；同 ID 的新版本保留旧目录，不能改写已发布样式。改变布局引擎时注册新 renderer 分支，保留旧渲染器兼容路径。
3. 新样式使用独立命名空间，不能覆写其他母版的 `.comic-*` / `.semantic-*` 类；若复用旧引擎需要先引入版本作用域并覆盖共存回归测试。当前只有一种内置母版，尚未添加切换菜单。
4. 更新精确 Git 提交白名单。不得开放整个素材目录，禁止业务截图、客户稿件、字体二进制混入。
5. 验证空目录安装、母版混用、缺失资源、未知版本、ZIP 往返、独立 HTML 和既有母版截图。运行 `npm run test:acceptance`。

母版 CSS 按版本管理；共用播放器和布局算法仍可能随修复更新，不能把 ZIP 的母版引用误称为所有浏览器上像素完全冻结。需要严格冻结时使用独立 HTML，并保留交付时工具版本。
