## 当前版本操作
- 顶部项目名称可修改。一个项目包含当前编辑内容和多个已保存版本。
- 顶部“版本”：保存为新版本，或导入 `.deck.zip` 为新版本；导入不会替换当前编辑内容。加载版本时选择另存、更新已有版本或丢弃当前内容，也可取消。
- 每个版本可加载、播放、删除及导出 ZIP；导出名称为“项目名称 · 版本名称.deck.zip”。
- 右侧“文字内容 / 素材与排版 / Codex 改稿”切换编辑。页面样式在“素材与排版”里。
- “让 Codex 修改”先生成建议，预览后再应用；模型设置在“高级设置”。待处理反馈可以勾选一起提交。
- 视频双击或触屏双点放大，再双击/双点还原；图片与 GIF 沿用点按放大。素材和页面支持拖拽排序。
