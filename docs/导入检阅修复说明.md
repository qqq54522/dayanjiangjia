# 导入检阅修复：可见素材、母版与评审

本轮修复保留旧母版 1.0.0，新建/改编采用 1.1.0。点击“改回默认排版样式”时采用当前默认母版。已有稿件和固定版本不被批量改写。

## 图片提取

过去按媒体关系表枚举附件，会包含未使用图片，却丢失同一文件多次裁剪的区别。现在按可见页面实例读取普通图片、形状填图、组合坐标、裁剪、翻转和旋转。过滤隐藏、画布外对象；部分画布外内容按可见范围裁剪。原媒体文件不直接作为可见事实输入。

组合图既保留组内媒体，又附上原页组合区域的静态画面。GIF 保留动画，视频转成兼容 MP4，并提供抽帧识别。不能安全还原的异形/不支持素材尝试静态区域回退并提示，绝不把静态回退称为保留动画。普通矩形、圆角矩形可舍弃旧稿装饰，保留内部图像。

原来的十二张图片截断改为分批素材索引，每批六格，所有素材均有编号。索引供模型定位，不要求用户辨认内部文件名。组合区域依赖 LibreOffice 原页渲染，其字体/复杂遮挡与 PowerPoint 仍可能不同；这不是任意 PPT 效果的像素级还原器。

## 呈现和审核

- 原稿参考的可见范围、关键事实与整体关系写入共用 Harness。
- 修复导入建议未应用时缺少母版背景的问题。
- 新母版改善长标题、封面、左右数据/素材布局、空标题框和稀疏流程。
- 导入记录显示时间；生成数与确认数分别显示；打开记录后持续更新任务状态。
- 整稿和单页参考生成均测量实际渲染，检查文字/卡片边界溢出、素材过小及加载失败；有问题时禁止直接采用，并将问题带入重新生成。
- 增加放大检查入口，解析警告直接展开。版本保存仍独立于生成、应用。

## 验证边界

使用用户业务 PPT 的本机隔离目录做 29 页素材解析，以及关键页真实 Codex 生成和浏览器检查。业务文件、抽取素材、日志与截图不提交到代码仓库。程序回归包含重复裁剪、隐藏对象、组合坐标、形状填图、部分画布外素材、动画/视频与原有 ZIP/版本流程。

实际溢出检测是验收关口，不代表模型每次都能一次生成合格页面；密集课程矩阵仍需根据提示重新组织。复杂嵌套组合的旋转/蒙版/遮挡、PPTX 与 PDF 的自动配对差异确认、整稿叙事的自动去重合并、循环/分组矩阵的专门模板，尚不能视为完整解决。已知局限应继续在检阅中记录，不能用“测试通过”替代逐页事实与演讲效果检查。
