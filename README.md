# 洋葱学园直播工作台 · 本地协作版

工具代码共享在公司 GitLab。每人运行自己的工作台，使用自己的 Codex 改稿和开发功能。文稿和图片保存在本机，通过内部飞书传送文稿包；不存入代码仓库。

## 第一次使用

需要 Git、Node.js 24 或更新版本，以及公司 GitLab 的仓库权限/SSH 配置。请让自己的 Codex 阅读 [AGENTS.md](AGENTS.md)，执行：

```sh
npm run setup
npm start
```

打开 http://127.0.0.1:8788 。Mac 也可以双击 `启动工作台.command`。无需 Pages、Cloudflare、模型 API Key 或他人的 ChatGPT 账号。首次安装需要联网下载依赖；工作台绑定本机，安装后可离线编辑。

## 日常使用

- 右侧编辑文字，上传图片/GIF；多选图片会进入同页轮播区。点击展示区放大，Esc 关闭。
- 点击保存才持久化页面。反馈提交会同时保存当前稿件。
- 点击“交给 Codex”，把生成的指令发到**此项目对应的本机 Codex 对话**。Codex 读取本机反馈，提交建议，用户在网页预览后应用。
- 生成固定播出版本后，后续改稿不会改变它。播放链接仅对本机有效。
- 文稿尚未做长期效果或营销事实核验，工具不会自动给出提分承诺。

## 与同事交换文稿

版本 → **导出文稿包（含图片/GIF）** → 得到一个 `.deck.json` 文件 → 通过内部飞书手动发送 → 对方在版本里**导入文稿包**并保存。无须额外发素材文件夹。包中包含页面、图片/GIF、讲述提示、反馈及固定版本。

上传每张图片上限20MB，文稿包导入上限100MB。便携包只支持已上传到本机的图片；外部图片请先下载、上传。旧版纯 JSON 不包含图片，发送方应使用含素材的新文稿包。导出的独立 HTML 用于播放，不可代替可编辑文稿包。

当前一个工作台保存一份当前工作区；切换项目先导出再导入，不自动合并两人分别修改的文稿。浏览器关闭后文稿仍保存在 `.local/workspace.sqlite`，每次写入前备份到 `.local/backups/`。图片在 `.local/media/`。不要删除 `.local/`，不要在两台电脑之间直接同步正在使用的数据库。

## 同步工具功能

在干净的 main 分支：`npm run update`。更新完成后重启服务、刷新网页。更新不操作文稿目录。

修改功能请让 Codex 建立 `codex/功能名` 分支，完成检查后运行：

```sh
npm run share-code -- "新增功能的简短说明"
```

脚本只暂存允许的代码路径、检查误入素材/凭证，提交后验证并默认合并 main，核对远端提交；另一人再更新。main 有其他更新时由 Codex 处理整合并重新验证。不是实时同步，也不自动合并冲突或覆盖未提交改动。

## 检查

`npm run doctor` 检查安装/服务；`npm run check` 执行类型检查与隔离测试；`npm run guard` 检查仓库文件边界。

技术：React + Vite、Node 内置 HTTP 与 SQLite。无云端数据库，不调用外部模型 API。所有自动化详细约定见 AGENTS.md。

## Pad 播放操作

轻点图片或 GIF 放大；放大后轻点图片或空白处收起。成组图片在图片区左右滑动切换，也可点至少 44px 高的上一张/下一张按钮。图片手势不会翻整页；在图片区外左右滑动翻页。Pad 上底部播放操作持续可见。离线 HTML 导出使用相同交互。

讲品模板使用品牌蓝、明黄、暖白配色。模板样式更新会影响工作台中所有版本的显示，固定版本保留的是内容快照；需要完全固定外观时，保留当场导出的独立 HTML。
