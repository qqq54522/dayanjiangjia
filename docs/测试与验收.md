# 自动验收

每次功能改动运行：

```sh
npm run test:acceptance
```

执行顺序：TypeScript 类型检查 → Node 单元/回归测试 → Vite 构建 → HTTP 集成验收。失败返回非零退出状态，share-code / merge-main 在验收失败时不会推送 main。用户要求暂不合并时，只运行验收，不运行同步脚本。

- `tests/gallery.test.mjs`：图片放大、轻点关闭、轮播、滑动点击抑制、多指/取消手势。
- `tests/video.test.mjs`：视频进度和静音传递、收起同步暂停、切换媒体/离页暂停。
- `tests/zip.test.mjs`：MP4/GIF 原始字节往返、素材去重、路径穿越/丢失/篡改拒绝。
- `tests/workspace.test.mjs`：版本、反馈、冲突检测和增量建议隔离。
- `acceptance/http.test.mjs`：启动两个临时服务与数据库，验证二进制上传、Range/HEAD/416、ZIP跨工作区导入、字体打包、跨站写拒绝。退出清理临时数据，不读写用户 `.local`。
- 测试 MP4 是 FFmpeg 生成的一秒纯色 H.264/AAC 样本，作为文本 fixture 保存；不包含业务内容。HTTP 测试用最小字体头占位，仅验证传输，不能代替真实字体渲染验收。

新增功能需要补充能检测回归的测试。`npm test` 为快速单元测试；`npm run test:acceptance` 为完整自动门禁。

## 浏览器与设备检查

Node 测试不等于 Pad 真机验收。使用隔离演示工作区人工或通过受支持的浏览器工具检查：MP4 能解码、主动开启声音、拖动进度、放大收起、切页无后台声音、字体加载后布局、实际导出/导入按钮、离线 HTML。

同一套 CSS 和媒体交互用于在线编辑/预演/离线导出。导出文件嵌入原字体和素材；字体加载失败会阻止正式播放并提示。不同系统仍可能存在抗锯齿差异，不承诺逐像素一致。

自动改稿测试覆盖默认/自定义模型、配置持久化、无 shell 参数调用、只生成建议、素材保留、并发拒绝、旧 revision 冲突、取消、重启中断、模型错误不降级，以及 HTTP 设置/跨站请求限制。模型网络请求不纳入每次自动验收，单独使用空白测试稿冒烟验证。

自由排版验收覆盖设计树校验、脚本/外链样式拒绝、自由设计随 ZIP 往返、恢复默认样式保留文案素材、模板模式清除自由设计。浏览器实测媒体点击、默认恢复备份和独立 HTML 渲染。
